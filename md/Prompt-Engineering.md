# Prompt：
就是给大模型的输入。

# 例如：
## 普通：
介绍一下台风

## 优化：
你是一名气象专家，请按照：
1.形成机制
2.生命周期
3.影响
4.案例

解释台风。
要求：
面向本科生，500字。

# 后者就是 Prompt Engineering/Prompt工程
Prompt Engineering = Prompt工程

# 为什么需要？
因为 LLM 本质不是数据库，是：

            输入文字
            ↓
            预测下一串最合理文字

所以如何描述任务，会极大影响结果。

# Prompt工程包含的内容：

## 1. 角色设定
你是一名Python专家

## 2. 任务拆解
第一步设计架构
第二步设计数据库
第三步写接口

## 3. 输出约束
输出JSON格式
不要解释

## 4. Few-shot/示例
也就是给例子，如：

输入：
天气晴朗

输出：
天气类型：晴

输入：
今天下雨

输出：
？

## 思维链 CoT、边界防护？

# 招聘里面：熟练Prompt工程/Prompt Engineering

实际要求：

不是会聊天，而是：

知道如何设计输入，让模型稳定完成任务，怎么让模型稳定工作

现在招聘里的 Prompt Engineering，范围扩大了：

它包括：

## Prompt设计

比如：

system prompt：

你是一个气象专家
回答必须基于知识库
禁止编造

## Prompt模板

比如：

你的RAG：

系统：
{system}

参考资料：
{context}

用户问题：
{question}

回答：

这里 {} 是动态填充。

## Prompt优化

比如：

原：

介绍台风

效果差。

优化：

请从形成条件、生命周期、影响三个方面解释台风。
面向本科生。
引用提供资料。

## Prompt安全控制

比如：

防止：

越权
Prompt注入
泄露系统提示
